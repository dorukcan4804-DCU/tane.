# Fotoğraflar

Ana sayfadaki büyük görsel için bu klasöre iki fotoğraf koy:

- `hero-meyve.jpg`: üstten çekilmiş, meyveyle dolu açık kutu

Yatay, en az 2400 px genişlikte olsunlar. Dosya varsa sitede çizimin yerine kendiliğinden görünür, yoksa çizim kalır.
